Keywords in C

32 special words that belong to the C language itself — not yours to name, only yours to use.

§1 What is a Keyword?
The words that C already knows — before you write a single line
A keyword is a word that is pre-defined by the C language. The compiler already knows what every keyword means and what it should do. You cannot change that meaning. You can only use them.
📖

Reserved by the Language

Keywords are "reserved" — the C standard has already claimed them. They are part of the grammar of C itself, not libraries or functions you wrote.

🔒

Fixed Meaning — Always

int will always mean integer. if will always mean a condition check. You cannot redefine or override their purpose.

🔡

Always Lowercase

Every C keyword is written in all lowercase. int is a keyword. Int and INT are NOT — C is case-sensitive.

🔢

Exactly 32 in C (C89/C90)

The original C standard defined exactly 32 keywords. Later standards (C99, C11) added a few more, but the core 32 are what every beginner must know.

§2 Why Do We Use Keywords?
Every keyword solves a specific problem in your program

Without keywords, you would have no way to tell the compiler: "store this data", "repeat this block", "make a decision here", or "this function returns nothing." Keywords are the commands you give to C.

📦

To Declare Data

You use int, char, float to tell the compiler what kind of data you want to store and how much memory to reserve.

🔀

To Make Decisions

if, else, switch let your program choose different paths based on conditions.

🔁

To Repeat Work

for, while, do let you run the same block of code multiple times without writing it again.

🗂️

To Organize Data

struct, union, enum let you group related data together under one name.

🏠

To Control Storage

auto, extern, static, register tell the compiler where and how long to keep a variable in memory.

↩️

To Return from Functions

return sends a value back from a function. void says a function returns nothing at all.

§4 The Golden Rule — Keywords are NOT Variable Names
The most common mistake beginners make
⚠️ IMPORTANT RULE
You cannot use any keyword as the name of a variable, function, or any identifier you create. Keywords already have a job — you cannot give them a second job. The compiler will throw an error immediately.
❌ WRONG — keyword as variable name
int int = 10;       // ERROR
int for = 5;        // ERROR
char return = 'A';  // ERROR
float if = 3.14;    // ERROR
int void = 0;       // ERROR
Compiler says: "error: expected identifier" — because these words are already taken by C.
✅ CORRECT — your own names
int number = 10;
int counter = 5;
char grade = 'A';
float pi = 3.14;
int isEmpty = 0;
Choose names that describe what the variable stores. Clear names make code readable.
❌ WRONG — tricky case variations
// Don't try to be clever:
int Int = 5;    // works but confusing
int IF = 10;    // works but terrible style
int While = 3;  // works but BAD practice
C is case-sensitive so Int is not int — but it tricks every reader of your code.
✅ CORRECT — descriptive names
int age = 5;
int maxScore = 10;
int loopCount = 3;
// Names that explain their purpose
Good variable names make your intent clear. Future-you will thank present-you.
📌 NOTE — CASE SENSITIVITY
int is a keyword.  Int and INT are technically valid identifiers (not keywords) — but never use them. It confuses every developer who reads your code and is considered very bad practice.
§5 Keywords in Action — A Quick Glimpse
See how many keywords appear even in a simple program
simple_program.c ↑ keywords highlighted in blue 
int main() {                          // int, return type keyword

    int marks = 85;                   // int, data type keyword
    float percentage = 85.5f;         // float, data type keyword
    char grade;                        // char, data type keyword

    if (marks >= 90) {                 // if, flow control keyword
        grade = 'A';
    } else if (marks >= 75) {         // else, flow control keyword
        grade = 'B';
    } else {
        grade = 'C';
    }

    int i;
    for (i = 0; i < 3; i++) {         // for, loop keyword
        if (i == 1) continue;          // continue, loop control keyword
        printf("Round %d\n", i);
    }

    return 0;                          // return, function return keyword
}
🔍 COUNT THEM
In just this small program: int × 3, float, char, if × 2, else × 2, for, continue, return — that's 13 keyword uses from just 8 unique keywords. Keywords are everywhere in your programs.
