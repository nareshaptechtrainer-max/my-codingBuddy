§1 Arithmetic Operators
The five operators that do math — the foundation of every calculation in C
➕

Arithmetic (+ − * / %)

Perform basic mathematical operations on numeric values
+AdditionAdds two operands — a + b

    printf("Mod:  %d\n", a % b);

    /* float division — cast first! */
    printf("Real: %.2f\n", (float)a / b);
    return 0;
}

§2 Relational Operators
Compare two values — always return 1 (true) or 0 (false)
⚖️

Relational (< <= > >= == !=)

Ask "is this relationship true?" — the answer drives every if/while decision
<Less than1 if left is strictly smaller than right

§3 Logical Operators
Combine conditions — &&, ||, ! — with short-circuit evaluation
🔗

Logical (&& || !)

Combine multiple boolean conditions into one decision
&&Logical AND1 only if BOTH sides are non-zero. Short-circuits: if left is 0, right is never evaluated
||Logical OR1 if EITHER side is non-zero. Short-circuits: if left is 1, right is never evaluated
!Logical NOTFlips truth: !0 = 1, !1 = 0, !42 = 0
Truth Table — &&
A=1 B=1  →  A&&B = 1
A=1 B=0  →  A&&B = 0
A=0 B=1  →  A&&B = 0
A=0 B=0  →  A&&B = 0

A=1 B=1  →  A||B = 1
A=1 B=0  →  A||B = 1
A=0 B=1  →  A||B = 1
A=0 B=0  →  A||B = 0
Short-circuit Demo
int x = 0;
// Right side never runs!
if (x != 0 && (10/x > 2))
    printf("safe");
// Without short-circuit: div by 0!

int a = 5;
if (a > 0 || expensive_fn())
    printf("fast");
// expensive_fn() never called!
LEAP YEAR (classic)
int y = 2024;
int leap = (y%4==0 && y%100!=0)
        || (y%400==0);
printf("%s", leap?"Leap":"Not leap");
TRIANGLE VALID CHECK
int a=3,b=4,c=5;
if(a+b>c && b+c>a && a+c>b)
    printf("Valid triangle");
else printf("Invalid");
LOGIN CHECK
int user_ok = 1, pass_ok = 1;
if (user_ok && pass_ok)
    printf("Welcome!");
else
    printf("Access denied");
NOT OPERATOR
int logged_in = 0;
if (!logged_in)
    printf("Please login");
// !0 = 1 (true)
§4 Bitwise Operators
Work at the bit level — the fastest operations a CPU can do
🔢

Bitwise (& | ^ ~ << >>)

Manipulate individual bits — used in embedded systems, compression, cryptography, flags
&Bitwise ANDBit is 1 only if BOTH corresponding bits are 1
|Bitwise ORBit is 1 if EITHER bit is 1
^Bitwise XORBit is 1 if bits are DIFFERENT (exclusive or)
~Bitwise NOTFlips every bit: ~5 = -6 (two's complement)
<<Left ShiftShifts bits left by n positions = multiply by 2ⁿ
>>Right ShiftShifts bits right by n positions = divide by 2ⁿ
Bit Patterns
a  = 12  = 0000 1100
b  =  5  = 0000 0101

a&b = 4  = 0000 0100  (AND)
a|b = 13 = 0000 1101  (OR)
a^b = 9  = 0000 1001  (XOR)
~a  = -13= 1111 0011  (NOT)

a<<1 = 24 = 0001 1000  (*2)
a>>1 = 6  = 0000 0110  (/2)
Common Bit Tricks
// Check if bit 3 is set
if (n & (1 << 3)) ...

// Set bit 2
n = n | (1 << 2);

// Clear bit 2
n = n & ~(1 << 2);

// Toggle bit 2
n = n ^ (1 << 2);

// Multiply by 8 fast
n = n << 3;  // same as n*8
CHECK EVEN/ODD (bit trick)
int n = 7;
if (n & 1) printf("Odd");
else printf("Even");
// Bit 0 = 1 means odd
SWAP WITHOUT TEMP
int a=10, b=20;
a = a ^ b;  // a=30
b = a ^ b;  // b=10
a = a ^ b;  // a=20
POWER OF 2 CHECK
int n = 16;
if (n>0 && (n & (n-1)) == 0)
    printf("Power of 2"); // YES
// 16=10000, 15=01111 → AND=0
COLOR FLAGS (bitmask)
#define RED   1  // 001
#define GREEN 2  // 010
#define BLUE  4  // 100
int color = RED | BLUE; // 101=5
if (color & RED) printf("Has Red");
FAST MULTIPLY / DIVIDE
int n = 6;
printf("%d", n << 2); // 24 (n*4)
printf("%d", n >> 1); // 3  (n/2)
COUNT SET BITS
int n=13, cnt=0; // 1101
while(n) {
    cnt += n & 1;
    n >>= 1;
}
printf("%d",cnt); // 3

§6 Increment & Decrement Operators
The ++ and -- operators — pre vs post makes a huge difference
🔄

++ and --

Add or subtract 1 — but WHEN it happens depends on pre/post position
++aPre-incrementIncrement a FIRST, then use the new value in the expression
a++Post-incrementUse the current value FIRST, then increment a
--aPre-decrementDecrement a FIRST, then use the new value
a--Post-decrementUse the current value FIRST, then decrement a
Pre vs Post Comparison
int a = 5;
int x = ++a;  // a becomes 6, x=6
printf("%d %d", a, x); // 6 6

int b = 5;
int y = b++;  // y=5, then b=6
printf("%d %d", b, y); // 6 5
In Loops
// Both print 0 1 2 3 4 — same!
for(int i=0; i<5; i++) ...
for(int i=0; i<5; ++i) ...

// But in expression — different!
int i=3;
printf("%d", i++); // prints 3
printf("%d", i);   // prints 4

printf("%d", ++i); // prints 5
printf("%d", i);   // prints 5
POINTER TRAVERSAL
int arr[] = {10,20,30};
int *p = arr;
printf("%d", *p++); // 10 (then p++)
printf("%d", *p);   // 20
ARRAY INDEX TRICK
int a[5]={0}, i=0;
a[i++] = 10; // a[0]=10, i=1
a[i++] = 20; // a[1]=20, i=2
a[i++] = 30; // a[2]=30, i=3
COUNTDOWN
int n = 5;
while(n > 0)
    printf("%d ", n--); // 5 4 3 2 1
TRICKY EXPRESSION
int a = 5;
int b = a++ + ++a;
// Undefined behavior! Never do this
// In real code: avoid mixing ++
// with same var in one expression
§7 Ternary Operator
The only C operator with three operands — a compact if-else
🎯

condition ? value_if_true : value_if_false

Evaluate a condition inline — pick one of two values. Cleaner than if-else for simple choices.
Syntax Explained
// condition ? expr1 : expr2
// If condition != 0 → expr1
// If condition == 0 → expr2

int a=10, b=20;
int max = (a > b) ? a : b;  // 20
int min = (a < b) ? a : b;  // 10
int abs = (a < 0) ? -a : a; // 10
Nested Ternary (use carefully)
int marks = 75;
char *grade = (marks >= 90) ? "A"
            : (marks >= 80) ? "B"
            : (marks >= 70) ? "C"
            : "F";
printf("%s", grade); // C
ODD / EVEN
int n = 7;
printf("%s", n%2==0 ? "Even":"Odd");
// Output: Odd
SIGN CHECK
int n = -5;
printf("%s", n>0 ? "Positive"
           : n<0 ? "Negative"
           : "Zero"); // Negative
MAX OF THREE
int a=3,b=7,c=5;
int max = (a>b&&a>c)?a:(b>c?b:c);
printf("%d", max); // 7
PRINTF CONDITIONAL
int count = 1;
printf("%d item%s", count,
       count==1 ? "" : "s");
// "1 item" (no extra s)

§9 Logic Builder
Think through these problems step by step — then reveal the answer
Problem 1: What does printf("%d", 5 + 3 * 2 - 1) print?
1What are all operators here? (+, *, -)
2Precedence: * is level 3, + and - are level 4. So * runs first.
33 * 2 = 6 → expression becomes 5 + 6 - 1
4+ and - are same level, L→R: 5+6=11, then 11-1=10
Output: 10
Rule: * before + and −, same-level goes left-to-right.
Problem 2: int a=5; printf("%d %d", a++, a) — what prints?
1a++ is post-increment: use a (5) now, increment later
2The second argument sees a after the increment? Depends on evaluation order!
3Function argument evaluation order is UNSPECIFIED in C — could be 5 5 or 5 6
Undefined / Implementation-defined!
Output varies by compiler. Never mix post-increment with the same variable in one printf call.
Problem 3: printf("%d", 7 & 3) — trace the bits
17 in binary = 0111
23 in binary = 0011
3AND: bit is 1 only when BOTH are 1 → 0011 = 3
Output: 3
7 (0111) AND 3 (0011) = 0011 = 3
Problem 4: What is the value? int x = (0 || 5) && (3 && 0)
1Evaluate (0 || 5): 0 is false, 5 is true → result = 1
2Evaluate (3 && 0): 3 is true, 0 is false → result = 0
3Now 1 && 0 → false = 0
x = 0
(1) && (0) = 0. Even though left side was true, right side killed it.

Errors every beginner makes — know them before your compiler surprises you
❌ WRONG
if (a = 5)   // assignment!
    printf("five");
Always true — assigns 5, not compares
✅ CORRECT
if (a == 5)  // comparison
    printf("five");
Use == to compare, = only to assign
❌ WRONG
int a=7, b=2;

Integer / integer = integer (truncates)
✅ CORRECT
float r = (float)a / b; // 3.5
Cast at least one operand to float first
❌ WRONG
int a=5;
printf("%d", a+++a); // UB
Undefined — modifying and reading same var
✅ CORRECT
int a=5;
int tmp = a++;
printf("%d", tmp + a); // 11
Separate side effects onto different statements
❌ WRONG
int n = 5 % 2.0; // compile error
// % only works on integers
✅ CORRECT

double r = fmod(5.0, 2.0); // 1.0
Use fmod() from math.h for float remainder
❌ WRONG

// Parses as (0 < x) < 10
// (0 or 1) < 10 is always true
✅ CORRECT
if (x > 0 && x < 10) // correct
    printf("in range");
C has no chained comparisons — use && to combine
❌ WRONG
int a=2, b=3;
int c = ~a + b; // not -(2)+3 !
// ~2 = -3 (two's complement)
✅ CORRECT

§12 Interview Thinking
Questions interviewers actually ask about operators in C
Q1: What is the difference between = and == in C?
= is the assignment operator — it stores a value. == is the equality operator — it compares two values and returns 1 or 0. Using = inside an if assigns the value and evaluates to that value (often a non-zero bug).
Q2: What is operator precedence and why does it matter?
Precedence determines which operator runs first when multiple operators appear in one expression. 2 + 3 * 4 = 14 (not 20) because * has higher precedence than +. Without it, expressions would be ambiguous.
Q3: What is short-circuit evaluation? Give an example.
In &&, if the left side is false, the right side is never evaluated. In ||, if the left is true, the right is skipped. Example: if (p != NULL && p->val > 0) — if p is NULL, the second part is never reached, preventing a crash.
Q4: What does a++ vs ++a mean? When does it matter?
a++ (post): use current value, then increment. ++a (pre): increment first, then use new value. In a simple statement like a++; both are identical. It matters when the expression's value is used: int x = a++ stores old value; int x = ++a stores new value.
Q5: How do you check if the nth bit is set in an integer?
Use: if (num & (1 << n)). This creates a mask with only bit n set, then ANDs with num. If the result is non-zero, bit n is set.
Q6: What is the result of sizeof('A') in C?
4 (not 1). In C, character literals like 'A' are of type int, not char. So sizeof('A') = sizeof(int) = 4. Only sizeof((char)'A') or sizeof(char) gives 1. (This is different from C++.)
Q7: Can you use the % operator on floating-point numbers?
No. The % operator works only on integer types (int, long, etc.). For floating-point modulus, use fmod() from <math.h>. Example: fmod(5.5, 2.0) = 1.5.
§13 CoddingBuddY Logic Rules

🔑 The 5-Question Framework for Every Expression

  • 01
    What operators are here? List every symbol in the expression before evaluating anything.
  • 02
    What are their precedence levels? Lowest level number wins. Group high-priority operators first.
  • 03
    What is the associativity? For equal-priority operators, check if they go L→R or R→L.
  • 04
    Are there any side effects? Does ++ or -- appear? Is the same variable used multiple times? Beware undefined behavior.
  • 05
    What type is the result? int / int = int. int / float = float. Verify type before printf format.
