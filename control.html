if / else if / else — the decision chain

Checked top to bottom; exactly ONE branch runs

🎬 Animation — grading with a chain

Rules that beginners break

  • The condition needs parentheses: if (marks >= 60) — and NO semicolon after it! if (x > 5); ends the if instantly.
  • = assigns, == compares. if (x = 5) compiles fine and is always true — C won't save you like Python does.
  • In C, 0 = false and anything non-zero = true. if (n) means "if n isn't zero".
  • Braces optional for one statement — but ALWAYS write them. The famous Apple "goto fail" bug came from a brace-less if.
the ternary shortcut 
// condition ? value_if_true : value_if_false
int bigger = (a > b) ? a : b;
printf("%s", marks >= 40 ? "PASS" : "FAIL");
02

switch — the jump table

One look at the value, straight to the matching case

🎬 Animation — watch the break work

Fall-through — bug AND feature

missing break = chaos 
switch (day) {
    case 1: printf("Mon");   // no break!
    case 2: printf("Tue");   // runs too!
    default: printf("??");   // and this!
}
// day = 1 prints: MonTue??
deliberate fall-through — grouping cases 
switch (ch) {
    case 'a': case 'e': case 'i':
    case 'o': case 'u':
        printf("vowel");
        break;
    default:
        printf("consonant");
}
💡
switch vs if/elseswitch: ONE value against fixed constants (menu choices, grades, days). if/else: ranges and complex conditions. switch can't do case marks >= 60.

The three loops

for = known count · while = unknown count · do-while = at least once

🎬 Animation — for loop, part by part

🎬 Animation — while countdown

for — count is known 
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
// init ; condition ; update
// 1 2 3 4 5
while — count unknown 
int n = 1234, digits = 0;
while (n > 0) {
    n = n / 10;
    digits++;
}
// digits = 4
do-while — at least once 
int choice;
do {
    printf("1.Play 2.Exit: ");
    scanf("%d", &choice);
} while (choice != 2);
// menus: show FIRST, ask after
♾️
Infinite loop checklistSomething inside the loop must push the condition toward false. while (n > 0) with no n-- inside runs forever. Stuck? Ctrl+C kills it.
04

break & continue — the emergency exits

break leaves the loop; continue skips one lap

🎬 Animation — break on first match

continue — skip, don't quit 
for (int i = 1; i <= 6; i++) {
    if (i % 2 == 0)
        continue;      // skip evens
    printf("%d ", i);  // 1 3 5
}
  • break exits only the INNERMOST loop — nested loops need a flag or a function return.
  • continue in a for loop still runs the update (i++) — in a while it jumps straight to the condition (mind your counter!).
  • goto exists in C. Interview answer: "I know it exists; structured code doesn't need it."
🔍
Classic useLinear search IS "loop + break": scan until found, break, and check afterwards whether you found it or ran out.
05

Nested loops — star patterns

The exam favorite: outer loop = rows, inner loop = what's IN a row

right triangle 
for (int i = 1; i <= 4; i++) {
    for (int j = 1; j <= i; j++)
        printf("*");
    printf("\n");
}
/*  *
    **
    ***
    ****  */
pyramid 
for (int i = 1; i <= 4; i++) {
    for (int s = 4 - i; s > 0; s--)
        printf(" ");
    for (int j = 1; j <= 2*i - 1; j++)
        printf("*");
    printf("\n");
}
number square 
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++)
        printf("%d ", i * j);
    printf("\n");
}
/* 1 2 3
   2 4 6
   3 6 9 */
🧠
The one trick for ALL patternsAsk two questions per row i: how many SPACES? how many STARS/numbers? Write each answer as its own inner loop. Every pattern question falls to this.
