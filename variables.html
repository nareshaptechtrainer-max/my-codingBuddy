What is a Variable? The Real Idea

💡 Concept (2 sentences)

A variable is a named box in memory that stores a value so you can use it later. You give it a name, tell C what type of data it will hold, and C reserves the right amount of memory for it.

📌

The rule: Every variable needs a type (what kind of data), a name (what to call it), and a value (what to put inside).

Syntax 
// type  name  =  value;
int    age  =  20;

// Multiple variables
float  gpa    = 8.5;
char   grade  = 'A';

// Declare first, assign later
int marks;
marks = 95;

🔡 Format Specifiers — The Secret Code

When using printf or scanf, you must tell C what type the variable is using a format specifier. Wrong specifier = garbage output or crash.

Format Specifiers in Action
int    age   = 20;
float  gpa   = 8.5;
char   grade = 'A';
double pi    = 3.14159;

printf("Age:   %d\n",  age);    // int
printf("GPA:   %f\n",  gpa);    // float
printf("GPA:   %.2f\n",gpa);    // 2 decimals
printf("Grade: %c\n",  grade);  // char
printf("Pi:    %lf\n", pi);     // double

Logic Builder — Think Before You Code

Don't start coding immediately. Answer these questions first. This is how real programmers think.

🧩 Problem 1
Store a student's name, age, and percentage — then print all three.
1
What information do I need to store? → name, age, percentage
2
What data type for each? → name: text, age: whole number, percentage: decimal
3
Which type maps to which? → name: char[], age: int, percentage: float
4
What format specifier for each? → %s, %d, %.2f
Solution
#include <stdio.h>

int main() {
    char  name[50] = "Ravi Kumar";
    int   age      = 20;
    float percent  = 87.5;

    printf("Name:       %s\n",    name);
    printf("Age:        %d\n",    age);
    printf("Percentage: %.2f%%\n", percent);

    return 0;
}
Output:
Name: Ravi Kumar
Age: 20
Percentage: 87.50%
🧩 Problem 2
Calculate the total price: 5 items at ₹49.99 each. Store and print the result.
1
What variables? → quantity (whole number), price per item (decimal), total (decimal)
2
Types? → int quantity, float price, float total
3
Operation? → total = quantity × price
Solution
#include <stdio.h>

int main() {
    int   qty   = 5;
    float price = 49.99;
    float total = qty * price;

    printf("Quantity: %d\n",     qty);
    printf("Price:    %.2f\n",   price);
    printf("Total:    %.2f\n",   total);

    return 0;
}

Common Mistakes — What Goes Wrong

These mistakes are made by 90% of beginners. Seeing them now means you won't make them.

❌ Mistake 1 — Wrong format specifier
✗ Wrong
float gpa = 8.5;
printf("%d", gpa); // WRONG!
✓ Correct
float gpa = 8.5;
printf("%f", gpa); // Correct
💡 Why it's wrong: %d reads data as integer bits. A float stored as bits looks like a completely different number. You'll see garbage like −858993460 instead of 8.5.
❌ Mistake 2 — Using variable before declaring
✗ Wrong
age = 20;         // Error!
int age;
✓ Correct
int age;
age = 20;         // Works
💡 Why it's wrong: C reads code top-to-bottom. You must declare a variable first so the compiler knows it exists and how much memory to reserve. Using it before declaring = "unknown identifier" error.
❌ Mistake 3 — Storing decimal in int (data loss!)
✗ Wrong (silent data loss)
int cgpa = 8.7;
// cgpa becomes 8 — .7 lost!
✓ Correct
float cgpa = 8.7;
// cgpa = 8.7 ✓
💡 Why it's wrong: int cannot store decimals — it silently chops off everything after the decimal point. No error, no warning — just wrong data. This is called truncation.
❌ Mistake 4 — Forgetting & in scanf
✗ Wrong (crash!)
int age;
scanf("%d", age);  // CRASH!
✓ Correct
int age;
scanf("%d", &age); // & = address
💡 Why it's wrong: scanf needs the address of the variable to know WHERE in memory to write the value. Without &, you're passing the variable's current value (garbage number) as an address — causing a segmentation fault / crash.

Quick Practice — 5 Exercises

Try thinking through each question yourself before revealing the answer. One step at a time.

1
Take a student's roll number and marks as input, print both.
▼
🧠 Logic

Roll number is a whole number → int. Marks could be decimal → float. Take input with scanf, print with printf.

💻 Code
C
#include <stdio.h>
int main() {
    int   roll;
    float marks;
    printf("Enter roll number: ");
    scanf("%d", &roll);
    printf("Enter marks: ");
    scanf("%f", &marks);
    printf("Roll: %d, Marks: %.2f\n", roll, marks);
    return 0;
}
📤 Output
Enter roll number: 101
Enter marks: 87.5
Roll: 101, Marks: 87.50
2
Store temperature in Celsius, convert to Fahrenheit, and print.
▼
🧠 Logic

Temperature can be decimal → float. Formula: F = (C × 9/5) + 32. Be careful: 9/5 in int division = 1. Write 9.0/5 for correct result.

💻 Code
C
#include <stdio.h>
int main() {
    float celsius, fahrenheit;
    printf("Enter Celsius: ");
    scanf("%f", &celsius);
    fahrenheit = (celsius * 9.0 / 5) + 32;
    printf("Fahrenheit: %.2f\n", fahrenheit);
    return 0;
}
📤 Output
Enter Celsius: 37
Fahrenheit: 98.60
3
Take two integers, swap their values, print before and after.
▼
🧠 Logic

Use a third (temp) variable as a temporary holder. Like swapping water between two glasses — you need an empty third glass. Classic logic-building question.

💻 Code
C
int a = 10, b = 20, temp;
printf("Before: a=%d, b=%d\n", a, b);
temp = a;   // save a
a    = b;   // a gets b's value
b    = temp;// b gets old a
printf("After:  a=%d, b=%d\n", a, b);
📤 Output
Before: a=10, b=20
After: a=20, b=10
4
Calculate area and perimeter of a rectangle. Take length and width as input.
▼
🧠 Logic

Length and width can be decimal → float. Area = l × w. Perimeter = 2 × (l + w).

💻 Code
C
float l, w, area, peri;
printf("Length: ");  scanf("%f",&l);
printf("Width:  ");  scanf("%f",&w);
area = l * w;
peri = 2 * (l + w);
printf("Area:      %.2f\n", area);
printf("Perimeter: %.2f\n", peri);
📤 Output
Length: 5
Width: 3
Area: 15.00
Perimeter: 16.00
5
Store a character grade. Print its ASCII value and the next grade in alphabet.
▼
🧠 Logic

char is secretly stored as an integer (ASCII code). 'A' = 65, 'B' = 66. So grade + 1 gives next letter. Print with %c for character, %d for ASCII.

💻 Code
C
char grade = 'A';
printf("Grade:        %c\n",   grade);
printf("ASCII value:  %d\n",   grade);
printf("Next grade:   %c\n",   grade+1);
📤 Output
Grade: A
ASCII value: 65
Next grade: B

Interview Thinking — Analytical Questions

Interviewers don't ask "what is a variable?" They ask WHY. Train your mind to answer analytically.

Q: Why use int for age and not float?
🔹 Age is always a whole number — no one is 20.7 years old in a system
🔹 int uses 4 bytes; float also uses 4 bytes — same size but unnecessary precision
🔹 Using float wastes CPU cycles for floating-point arithmetic on whole numbers
✅ Rule: Match the data type to the nature of the data
Q: What happens when you store 8.7 in an int?
🔹 Truncation happens — the decimal part is silently removed
🔹 int x = 8.7; → x becomes 8, not 9 (it does NOT round)
🔹 The compiler may give a warning but still compiles
✅ This is called implicit type conversion (type coercion)
Q: Why does int x; (no value) have garbage inside?
🔹 C reserves memory for x, but does NOT clear it
🔹 That memory location has leftover bits from a previous program
🔹 These leftover bits look like a random number — called garbage value
✅ Always initialize variables before using them
Q: float vs double — when to use which?
🔹 float — 4 bytes, 6–7 decimal digits of precision. Use for basic decimals
🔹 double — 8 bytes, 15–16 decimal digits. Use for scientific, financial calculations
🔹 Example: bank balance → double. Temperature → float is enough
✅ More precision = more memory. Choose wisely.
Q: What is the size of int — always 4 bytes?
🔹 Not always — it depends on the platform and compiler
🔹 On most 32-bit and 64-bit systems today: 4 bytes
🔹 On older 16-bit systems: 2 bytes
✅ Use sizeof(int) to check at runtime — never assume
Q: Why is char stored as a number (ASCII)?
🔹 Computers only understand numbers (0s and 1s)
🔹 ASCII is a mapping: 'A'=65, 'a'=97, '0'=48
🔹 char c = 'A'; actually stores 65 in 1 byte
✅ That's why char + 1 gives the next character
