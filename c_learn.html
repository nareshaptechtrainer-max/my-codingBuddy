Topic 01

Introduction to C

Why C? What is C? And what does your first C program actually do?

🌍 Why Learn C?

C is called the "Mother of All Languages". Java, Python, JavaScript — almost every modern language borrowed ideas from C. Learning C means you understand how a computer thinks, not just how a language works.

Real-Life Analogy

Learning C is like learning to drive a manual car. It's harder than automatic, but once you know it — you understand exactly what's happening under the hood. Every other car becomes easier after that.

  • Speed: C programs are blazing fast. Operating systems like Linux are written in C.
  • Control: You control memory directly. Nothing happens without you knowing.
  • Foundation: DSA, embedded systems, compilers — all use C concepts.

💡 #include <stdio.h> adds the "Standard Input Output" library — it gives you printf and scanf. Without it, C doesn't know what printf is.

⚙️ How a C Program Runs

Your code goes through 4 stages before it runs:

  1. Write — You type C code in a file (hello.c)
  2. Compile — Compiler converts C → machine code (gcc hello.c -o hello)
  3. Link — Connects your code with library functions
  4. Execute — The program runs (./hello)
✅ If you see error: 'printf' undeclared, it means you forgot #include <stdio.h>. That's the most common first mistake!

Topic 02

Variables & Data Types

Opening full interactive lesson...

📦 What is a Variable?

A variable is a named box in memory that holds a value. You give it a name, tell C what type of data it will hold, and then store a value.

Real-Life Analogy

Think of a variable like a labeled jar. int age = 20; is like writing "Age" on a jar and putting the number 20 inside. Anytime you need the age, you open that jar.

C — variables.c 
#include <stdio.h>

int main() {
    // Declaration + Initialization
    int age = 20;
    float gpa = 8.7;
    char grade = 'A';

    printf("Age: %d\n", age);
    printf("GPA: %.1f\n", gpa);
    printf("Grade: %c\n", grade);

    return 0;
}
Output
Age: 20
GPA: 8.7
Grade: A

📊 C Data Types

C needs to know what kind of data a variable will hold so it can allocate the right amount of memory.

⚠️ Common mistake: Using %d for a float gives garbage output. Always match the format specifier to the variable type!

🔡 scanf — Taking Input

scanf reads input from the keyboard and stores it in a variable. Notice the & (address-of) operator — we're telling scanf where in memory to put the value.

C — input.c 
#include <stdio.h>

int main() {
    int num;
    printf("Enter a number: ");
    scanf("%d", &num);     // & gives address of 'num'
    printf("You entered: %d\n", num);
    return 0;
}

Topic 03

Operators

The tools that let your program calculate, compare, and make decisions.

➕ Arithmetic Operators

Used to perform mathematical operations on numbers.

OperatorMeaningExampleResult
+Addition5 + 38
-Subtraction5 - 32
*Multiplication5 * 315
/Division10 / 33 (int!)
%Modulus (remainder)10 % 31
⚠️ Integer division: 10 / 3 gives 3, not 3.33. C chops off the decimal when both values are integers. Use 10.0 / 3 or cast to float for the actual result.

⚖️ Relational & Logical Operators

Used to compare values and combine conditions. They return 1 (true) or 0 (false).

C — operators.c 
#include <stdio.h>

int main() {
    int a = 10, b = 20;

    // Relational — compare values
    printf("%d\n", a == b);   // 0 (false)
    printf("%d\n", a < b);    // 1 (true)
    printf("%d\n", a != b);   // 1 (true)

    // Logical — combine conditions
    printf("%d\n", (a < b) && (b < 50));  // 1 (AND)
    printf("%d\n", (a > b) || (b < 50));  // 1 (OR)
    printf("%d\n", !(a < b));              // 0 (NOT)

    return 0;
}

🔧 Increment / Decrement & Assignment

C 
int x = 5;

x++;        // x becomes 6 (post-increment)
++x;        // x becomes 7 (pre-increment)
x--;        // x becomes 6 (post-decrement)

x += 10;   // x = x + 10 → shorthand assignment
x *= 2;    // x = x * 2
x %= 3;    // x = x % 3
Real-Life Analogy

x++ is like a ticket counter. It shows the current number first, then advances. ++x advances first, then shows the new number.

Topic 04

Control Flow

Make your program think — take different paths based on conditions.

🔀 if / else if / else

Real-Life Analogy

You wake up in the morning. If it's raining → carry an umbrella. Else if it's cloudy → wear a jacket. Else → wear casual clothes. Programs make the same kind of decisions.

C — grades.c 
#include <stdio.h>

int main() {
    int marks;
    printf("Enter your marks: ");
    scanf("%d", &marks);

    if (marks >= 90) {
        printf("Grade: A+\n");
    } else if (marks >= 75) {
        printf("Grade: A\n");
    } else if (marks >= 60) {
        printf("Grade: B\n");
    } else {
        printf("Grade: C\n");
    }

    return 0;
}

🔄 switch Statement

When you're comparing a variable to many fixed values, switch is cleaner than chained else if.

C — switch.c 
int day = 3;

switch(day) {
    case 1: printf("Monday\n");    break;
    case 2: printf("Tuesday\n");   break;
    case 3: printf("Wednesday\n"); break;
    default: printf("Other day\n");
}
Output
Wednesday
⚠️ Always use break in each case. Without it, C "falls through" to the next case — a common bug!
Topic 05

Loops

Repeat actions without repeating code. Loops are the backbone of every algorithm.

🔁 for Loop

Use for when you know in advance how many times you want to repeat.

Real-Life Analogy

Doing 10 push-ups: Start at 1 → do one → count + 1 → stop when you reach 10. That's exactly what a for loop does.

C — for_loop.c 
// Print 1 to 5
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
// Output: 1 2 3 4 5

// Sum of 1 to 100
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
printf("Sum = %d\n", sum);   // Sum = 5050

🔄 while & do-while Loops

C — while.c 
// while: check first, then execute
int i = 1;
while (i <= 5) {
    printf("%d ", i);
    i++;
}

// do-while: execute at least ONCE, then check
int n;
do {
    printf("Enter positive number: ");
    scanf("%d", &n);
} while (n <= 0);  // repeat until valid input
💡 When to use what? Use for when count is known. Use while when condition-based. Use do-while when the block must run at least once (like menus and input validation).

⭐ Classic Pattern: Nested Loops

C — star_pattern.c 
// Print a 5-row star triangle
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= i; j++) {
        printf("* ");
    }
    printf("\n");
}
Output
*
* *
* * *
* * * *
* * * * *
Topic 06

Functions

Break your program into reusable, manageable blocks of logic.

📦 What is a Function?

Real-Life Analogy

A function is like a coffee machine. You press a button (call the function), it runs a process internally, and gives you coffee (returns a value). You don't need to know HOW it makes coffee — just that it works.

C — functions.c 
#include <stdio.h>

// Function definition: return_type name(parameters)
int add(int a, int b) {
    return a + b;
}

void greet() {          // void = returns nothing
    printf("Hello, Buddy!\n");
}

int main() {
    greet();              // function call
    int result = add(5, 3);
    printf("Sum = %d\n", result);
    return 0;
}
Output
Hello, Buddy!
Sum = 8

🔄 Recursion

A function that calls itself. Essential for problems that have repeated sub-problems (factorial, fibonacci, tree traversal).

C — factorial.c 
int factorial(int n) {
    if (n == 0 || n == 1)
        return 1;           // base case — stop here
    return n * factorial(n - 1);  // recursive call
}

// factorial(4) = 4 * factorial(3)
//              = 4 * 3 * factorial(2)
//              = 4 * 3 * 2 * factorial(1)
//              = 4 * 3 * 2 * 1 = 24
✅ Every recursion needs a base case. Without it, the function calls itself forever and causes a stack overflow!
Topic 07

Arrays & Strings

Store and manage collections of data efficiently.

📋 Arrays

Real-Life Analogy

An array is like a train. Each compartment (index) holds one passenger (value). You access any compartment directly by its number — compartment 0, compartment 1, etc.

C — arrays.c 
#include <stdio.h>

int main() {
    // Declare array of 5 ints
    int marks[5] = {85, 92, 78, 95, 88};

    // Access by index (starts from 0)
    printf("First: %d\n", marks[0]);   // 85
    printf("Last: %d\n", marks[4]);    // 88

    // Loop through array
    int sum = 0;
    for (int i = 0; i < 5; i++) {
        sum += marks[i];
    }
    printf("Average: %.1f\n", (float)sum / 5);

    return 0;
}

🔡 Strings in C

C doesn't have a built-in string type. A string is just a character array that ends with '\0' (null terminator).

C — strings.c 
#include <stdio.h>
#include <string.h>   // for strlen, strcpy, etc.

int main() {
    char name[] = "Naresh";   // auto null-terminated
    printf("Name: %s\n", name);
    printf("Length: %lu\n", strlen(name));  // 6

    char greet[50];
    scanf("%s", greet);       // reads one word
    printf("Hi, %s!\n", greet);

    return 0;
}
Topic 08

Pointers

The superpower of C. Understand pointers and you understand memory itself.

📍 What is a Pointer?

A pointer is a variable that stores a memory address — not a value, but the location of a value.

Real-Life Analogy

Your friend's house has an address (say, "Block 3, Flat 12"). A pointer is like that address on a piece of paper. The paper isn't the house — but it tells you exactly where the house is. You can go there and get what's inside.

C — pointers.c 
#include <stdio.h>

int main() {
    int x = 42;
    int *p = &x;   // p stores the ADDRESS of x

    printf("Value of x:   %d\n", x);    // 42
    printf("Address of x: %p\n", &x);   // e.g. 0x7ffd...
    printf("p holds:      %p\n", p);    // same address
    printf("Value at p:   %d\n", *p);   // 42 (dereference)

    *p = 100;    // change x through the pointer
    printf("x is now: %d\n", x);       // 100

    return 0;
}
💡 & = "give me the address of"  |  * = "go to that address and give me what's there" (dereference)

🔗 Pointers & Functions (Pass by Reference)

In C, function arguments are copied by default. To modify the original variable, pass its address using a pointer.

C — swap.c 
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 10, y = 20;
    swap(&x, &y);    // pass addresses
    printf("%d %d\n", x, y);  // 20 10
}
Topic 09

Structures

Group related data together — the building block of objects in C.

🧱 What is a Structure?

Real-Life Analogy

A student has a name, age, and marks. Instead of 3 separate variables, a struct groups them under one "Student" blueprint — like a form that has multiple fields.

C — structs.c 
#include <stdio.h>

// Define the structure (blueprint)
struct Student {
    char name[50];
    int age;
    float marks;
};

int main() {
    // Create a variable of type Student
    struct Student s1;

    s1.age = 20;
    s1.marks = 92.5;

    printf("Age: %d\n", s1.age);
    printf("Marks: %.1f\n", s1.marks);

    // Array of students
    struct Student class[3];
    class[0].age = 19;

    return 0;
}
Topic 10

File I/O

Make your programs persistent — read from and write to files.

📁 Working with Files

Real-Life Analogy

File I/O is like a notebook. You open it, write something, and close it. Next time you open it, what you wrote is still there. Without files, data disappears when your program ends.

C — fileio.c 
#include <stdio.h>

int main() {
    // ── WRITE to a file ──
    FILE *fp = fopen("data.txt", "w");   // "w" = write mode
    if (fp == NULL) {
        printf("Error opening file!\n");
        return 1;
    }
    fprintf(fp, "Hello from CoddingBuddY!\n");
    fprintf(fp, "Score: %d\n", 95);
    fclose(fp);   // always close the file

    // ── READ from the file ──
    fp = fopen("data.txt", "r");   // "r" = read mode
    char line[100];
    while (fgets(line, sizeof(line), fp) != NULL) {
        printf("%s", line);
    }
    fclose(fp);

    return 0;
}
Output (reads data.txt)
Hello from CoddingBuddY!
Score: 95
ModeMeaning
"r"Read (file must exist)
"w"Write (creates or overwrites)
"a"Append (adds to end)
"r+"Read + Write
